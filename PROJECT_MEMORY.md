## Architecture and decisions

- Python CLI commands: `init-db`, `doctor`, `resume-info`, `adapters`, `companies add/import/list`, `scrape [--company]`, `rescore [--company] [--force]`, `serve`. Install from `pyproject.toml`; optional extras `ai`, `browser`, `test`. Dashboard at loopback port 8000; no Node build or embedded scheduler.
- Mongo collections: `companies`, `jobs`, `scraping_history`, `match_cache`, `metadata`. TLS verification via certifi, bounded timeouts, retryable driver operations plus bounded application retries. Credentials stay in `.env`; nested secret-looking adapter config keys and credential-bearing URLs are rejected.
- Unique indexes: partial `(company_id, external_job_id)` for string IDs; `(company_id, canonical_url)` fallback. Upserts preserve first-seen, refresh last-seen, track meaningful content changes and invalidate stale scores. URL-only identity can gain ATS ID without duplication; conflicting IDs/URLs fail explicitly. URL normalization preserves potentially functional parameters/path case/trailing slashes.
- Verified source posting evidence is mandatory, separately stored from first/last-seen. Insert and read filters enforce rolling UTC 72 hours and reject future/unverifiable dates. Source timezone required for naive/date-only data. Date-only uses local day start as a conservative cutoff; ambiguous/nonexistent DST times are excluded. Date semantics still require real source inspection by each adapter.
- Deterministic skill/keyword coverage is the default, clearly labeled as a heuristic. Optional LangChain `init_chat_model` + structured output supports OpenAI initially and other installed providers. No default paid model is chosen; configure `AI_MODEL`. Cache keys include resume text hash, meaningful job content and scorer/provider/model configuration. Contact data is redacted before optional external calls; raw resume text is not stored in Mongo/logs.
- Hybrid mode has a prefilter and logical call cap; SDK allows one retry per evaluation. Failed/deferred AI keeps a retryable deterministic score and does not poison completed-score cache. Budget deferrals yield partial history but exit 0; actual failures yield nonzero for service retries. Per-run budget is not a daily billing limit, and crashes before cache persistence can repeat charges.
- CLI, manual dashboard worker and systemd share an OS file lock in `STATE_DIR` for one Mac/Linux host. No distributed deployment support. Crashed locks release; subsequent runs mark unfinished history interrupted. Successful complete snapshots alone can close missing jobs. Conflicting duplicate batch rows fail before writes. Registering unimplemented companies yields disabled `awaiting_adapter` records.
- Jev was not integrated: no specific package/service was identified, and deterministic core decisions do not need another AI dependency. This is an explicitly deferred optional integration, not a claimed working feature.
